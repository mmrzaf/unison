# Generated artifacts and file recovery

Generated artifacts commit through explicit durable generation workflows. Previews and extracted text remain non-authoritative, and backup, restoration, archive handling, encrypted files, and file tests preserve accepted evidence.

## A generated artifact

Share file infrastructure without creating a generic artifact domain.

A generated artifact is a domain-owned immutable output of a governed process. Report Artifact and Tenant Export Artifact retain distinct meaning and each references exactly one Attachment.

## Expose only validated complete output

Waiotech must expose only validated complete output.

The process loads exact inputs, creates temporary bytes, validates format and completeness, computes digest, performs safety processing, finalizes storage, and commits artifact, Attachment, governing link, and completed process state consistently.

## Never present partial output as complete

Waiotech must never present partial output as complete.

No completed artifact exists. Partial bytes remain unavailable and disposable; the process preserves safe failure and retry evidence.

## Prevent derived file processing from becoming hidden product truth

Waiotech must prevent derived file processing from becoming hidden product truth.

They are derived, rebuildable, access-controlled representations linked to the source Attachment. Extracted facts become authoritative only through an explicit domain action.

## Fail closed on content that cannot be inspected safely

Fail closed on content that cannot be inspected safely.

Archive processing enforces expansion, nesting, traversal, file-type, and encryption limits. Password-protected or encrypted files are rejected unless a complete Product Authority and security handling contract exists.

## Restore metadata and bytes as one evidence system

Restore metadata and bytes as one evidence system.

Recovery verifies PostgreSQL Attachment records, links, artifact records, object existence, size, digest, classification, and Tenant partitioning. Missing bytes leave the Attachment unavailable rather than erased.

## Verify ingestion, evidence, security, storage, and recovery independently

Waiotech must verify ingestion, evidence, security, storage, and recovery independently.

Tests cover hostile filenames, size, streaming, media spoofing, digests, safety failure, quarantine, Tenant isolation, governing access, additional links, direct upload, delegated URL, immutable storage, correction, orphan cleanup, artifacts, backup, and adapter conformance.
