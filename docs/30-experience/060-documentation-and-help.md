# Documentation and Help Center

Documentation and Help Center provides bilingual, persistent, contextual product guidance and governed deep links. Guides explain product use without becoming independent Product or Engineering Authority.

## The Documentation and Help Center

Waiotech must provide an integrated permanent Help Center rather than a link directory.

The Documentation and Help Center is the permanent bilingual learning, explanation, contextual-help, and troubleshooting capability inside Tenant Dashboard.

It replaces a page that merely lists documentation links.

## Maintain bilingual documentation parity

Waiotech must maintain bilingual documentation parity.

It provides complete English and Persian content.

Both language editions must communicate equivalent concepts, workflows, blockers, safety information, and mission instructions. Canonical codes remain unchanged; presentation text is localized.

## Organize help around concepts, tasks, roles, and problems

Organize help around concepts, tasks, roles, and problems.

The Help Center includes:

- concept explanations;
- canonical terminology;
- task-based guides;
- role-relevant learning paths;
- action and lifecycle explanations;
- Permission and responsibility explanations;
- evidence guidance;
- troubleshooting;
- error-code guidance;
- field-work guidance;
- links to related subjects and actions.

## Keep user documentation explanatory and authority-aligned

Waiotech must keep user documentation explanatory and authority-aligned.

Documentation explains Product Authority and supported product behavior. It must remain aligned with authority but cannot introduce or override a product rule.

## Keep documentation permanently available as product help

Waiotech must keep documentation permanently available as product help.

Documentation availability is independent from mission completion, assessment result, Tenant state, and onboarding progress, subject only to ordinary authentication and content-access rules.

## Contextual help

Waiotech must make guidance available at the point of work without losing user input.

Contextual help connects a product page, form, field, action, lifecycle condition, blocker, or error code to the applicable guide.

It must preserve the User's unfinished work when opened and permit navigation back to the relevant product context.

## Use deep links for navigation, never authority

Waiotech must use deep links for navigation, never authority.

A guide may link to the relevant Dashboard page, record type, action, or form. Android field guides may link to the applicable Work App screen.

A guide link does not bypass authentication, Permission, Tenant context, lifecycle, or Readiness.

## Interactive onboarding

Teach product work through guided practice.

Interactive onboarding consists of task-based guided missions that teach concrete Waiotech workflows through safe product interaction.

It is not limited to passive introduction screens or completion checklists.
