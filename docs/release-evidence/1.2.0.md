## Qualification actually performed

All pre-tag evidence is automated and virtual; nothing was exercised on physical hardware.

- JVM unit suite, formatting, debug/release lint, debug/release assembly and Android-test
  compilation: `./scripts/build-release.sh` (includes `check-release-quality.sh`).
- Multi-peer JVM harness on virtual time (real `RoomRuntime`, handshake, admission, transfer
  orchestration): create/join, steady-state quietness, leave and coordinator loss, reconnect,
  half-open links, admission limits, transfers and failure injection, natural ends, interruptions,
  clock offset/drift, a slow player under a command flood, shutdown at random points, and seeded
  chaos soaks (sixteen 20-minute seeds in the release build) with a determinism check.
- API 33 emulator instrumented suite (`connectedDebugAndroidTest`), including real Media3 transient
  audio-focus and natural-boundary behavior.
- API 30/33/36 automated matrix runs in the tag workflow; the result is recorded in the Actions run.

## Not exercised

Hotspot, real-LAN, VPN and Bluetooth paths have **not** been tested on physical devices. Release
confidence for those paths rests on the emulator suite and the simulated transport.
