Waiotech PDF presentation assets

The HTML template and paged-media CSS in this directory are maintained
presentation inputs used by the repository documentation generator.

Generate cumulative Markdown:

    just docs

Generate cumulative Markdown and the styled PDF:

    just docs-pdf

The generated files are written to:

    docs/90-generated/010-waiotech.md
    docs/90-generated/020-waiotech.pdf

Generated output is derived from the numbered maintained documentation and must
not be edited directly.
