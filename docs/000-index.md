# Waiotech documentation

Waiotech is the professional operating system for one wastewater plant. It connects a coherent Plant Model with Process Operations, Maintenance, Inventory, Reliability, evidence, and accountable plant decisions so staff can understand what is happening, act with confidence, and preserve what the plant learned.

This documentation is the canonical authority for Waiotech product meaning, engineering guarantees, and user experience.
