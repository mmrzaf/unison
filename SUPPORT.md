# Support

- **Reproducible bugs:** use a GitHub bug-report Issue.
- **Questions, setup help, and ideas:** use GitHub Discussions.
- **Security vulnerabilities:** follow `.github/SECURITY.md` and do not open a public bug report.

Unison is a community/open-source project; support is best-effort. Include the app version, Android
version, device model, room role, network setup, and sanitized diagnostics when they are relevant.
