# Changelog

## 0.1.0

Initial complete source implementation of Unison:

- offline room discovery and direct join;
- collaborative queue and transport controls;
- local file playback with shared timeline;
- proactive peer-to-peer transfer and SHA-256 deduplication;
- library, playlists, M3U import/export with relative-folder recovery, temporary retention;
- coordinator recovery, reconnection, clock sync, and drift correction;
- Android 11–13 primary support with later-version compatibility structure;
- hardened scheduled playback projection, overlapping-command protection, reconnect behavior, transfer watchdogs, PIN throttling, and private release signing;
- corrected unknown M3U duration round-tripping and hotspot-interface prioritization;
- added an executable 40-test offline core validation suite and three Android Gradle frame-codec tests.
